# Blu SDK

This repository contains the SDK packages for Blu.

## Overview

The monorepo includes SDKs for browser, core, node, next, and react integrations.

## Main repository

The main Blu project lives here:

- https://github.com/arxja/blu

## Packages

- `@blu/core`
- `@blu/browser`
- `@blu/node`
- `@blu/next`
- `@blu/react`

## Getting started

Install dependencies and run the workspace commands from the repository root:

```bash
pnpm install
pnpm build
```

For more details, see the package documentation and source code in this monorepo.
